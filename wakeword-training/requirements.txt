# "Hey V.O.I.D." wake-word training pipeline dependencies.
#
# INSTALL INTO A DEDICATED VENV - NEVER INTO C:\V.O.I.D\.venv.
# That venv is Python 3.14; this training venv MUST be Python 3.12 (see
# README.md "Dependency discipline"). Verified working combination below -
# every line was determined empirically (actually installed and imported),
# not assumed. History of that verification:
#
#   1. openwakeword.train.Model and openwakeword.data.generate_adversarial_
#      texts both live in modules whose OWN top-level imports pull in far
#      more than what those two specific functions use: torch_audiomentations,
#      speechbrain, mutagen, and acoustics are all required just to IMPORT
#      openwakeword.train/openwakeword.data, regardless of which function is
#      actually called. Confirmed by iteratively importing and fixing
#      ModuleNotFoundError one package at a time.
#   2. `acoustics` (needed transitively, see above) depends on
#      scipy.special.sph_harm, which was removed in SciPy 1.15 (renamed to
#      sph_harm_y). A scipy pin below 1.15 is required - not a hack, a normal
#      compatible-version constraint - openwakeword itself only requires
#      scipy<2,>=1.3, so this stays within its own tolerance.
#   3. tensorflow-cpu==2.8.1, tensorflow-probability, onnx, onnx-tf, datasets,
#      and deep-phonemizer (all part of openwakeword's own `full` extra) are
#      NOT needed: traced via source inspection to openwakeword.train's
#      convert_onnx_to_tflite() (an optional ONNX->TFLite converter, function-
#      local imports, never called by this project - irrelevant since V.O.I.D
#      is ONNX-only on Windows) and to the out-of-vocabulary DeepPhonemizer
#      fallback in generate_adversarial_texts (never triggered - "hey" and
#      "void" are both confirmed present in the CMU pronouncing dictionary).
#      tensorflow-cpu==2.8.1 would not even install on Python 3.14 or 3.12
#      (its wheels only cover up to Python 3.10) - one of the two reasons a
#      separate Python 3.12 training venv exists at all (the other being
#      overall isolation from V.O.I.D's runtime venv).

pyyaml>=6.0
numpy>=2.0,<2.6
scipy>=1.10,<1.15          # acoustics (transitive) needs scipy.special.sph_harm

# Base openwakeword: openwakeword.train.Model (architecture + ONNX export),
# openwakeword.utils.AudioFeatures/download_models (feature extraction),

# which requires onnxscript - without it, export_to_onnx() raises
# ModuleNotFoundError. Discovered by running the export, not assumed.

torchinfo>=1.8
torchmetrics>=0.11
onnxscript>=0.1

# Required transitively just to IMPORT openwakeword.train/openwakeword.data
# (see history above) - not directly called by this project's own code.
torch-audiomentations>=0.11
speechbrain>=1.0
mutagen>=1.46
